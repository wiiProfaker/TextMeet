## Отложено на следующие планы (из ревью кода)

- План 2: перезапуск окна записи после сбоя его процесса и сброс признака «готово»; обработчик разрешений
  (`session.setPermissionRequestHandler`, разрешить только микрофон для окна записи); урезанное меню macOS
  (без «Перезагрузить» и инструментов разработчика); удаление пустой папки встречи, если создание встречи
  прервалось на полпути; сохранение незнакомых полей `meeting.json` при записи (библиотека может быть общей
  для разных версий программы через OneDrive).
- Из финального ревью ветки, до новых каналов IPC в Плане 2: единая таблица «канал → аргумент → ответ» в
  `shared/ipc.ts`, чтобы расхождение main и preload ловилось проверкой типов; порог покрытия считать по всем
  модулям `src/`, а не по списку; раздельные tsconfig для main/preload и для окон; сбрасывать признак выхода,
  если выход отменён (диалог «идёт запись»), и дописывать журнал перед выходом; понятные русские тексты для
  системных ошибок (`EACCES` и т. п.); папка встречи без `meeting.json` — состояние «создаётся», а не
  «повреждена»; Electron fuses в сборке (после разрешения на микрофон); `predev`/`prestart` со скачиванием
  Electron для свежей копии репозитория.
- Уборка временных папок, которые оставляют модульные тесты; обновить `actions/*@v4` → `@v5`
  (предупреждение GitHub об устаревании Node 20).

Сделано сразу по итогам финального ревью: у версии для разработки своя папка данных (`TextMeet-dev`) и своя
библиотека по умолчанию (`~/TextMeet-dev`) — она больше не уступает запуск установленной программе и не трогает
её данные; preload встраивает пакеты в себя; у сборок в GitHub Actions есть ограничение времени и прав.
