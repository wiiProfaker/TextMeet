## «Запись экрана» на Mac

Не выяснено: пользователь не помнит, спрашивала ли macOS разрешение «Запись экрана» при первом старте записи.
Запись микрофона и системного звука работает без замечаний. Вопрос остаётся открытым в
[итогах спайка](spike-results.md) — перепроверить при следующей чистой установке (`tccutil reset All dev.textmeet.app`,
затем «Начать запись» и посмотреть, какие окна покажет система).

## Итог

Всё работает на обеих системах. Библиотеку пользователь держит локально (не в общей папке OneDrive).

## Сделано сверх плана (по ревью кода, всё с тестами)

- Контроллер записи: гонки вокруг тайм-аута старта, падения окна записи и ошибки диска; сброс в «ожидание» только для
  своей записи; папка библиотеки фиксируется на всю запись; блокировка на время выхода, выход ждёт идущую остановку;
  запись останавливается, если пропали обе дорожки.
- Окно записи: микрофон освобождается, если запуск сорвался после его открытия; перезапуск окна не чаще 3 раз в
  минуту, дальше — «Запись не работает».
- Сведение `mix.opus`: сторож зависшего ffmpeg (останавливает жёстко — ffmpeg 7 на Linux не отвечает на SIGTERM,
  это поймал `ci` на `main` после слияния), очередь хранит `{libraryDir, id}`; неудачное сведение показывается
  как ошибка, а не бесконечное «Готовим…».
- Удаление папки встречи — с повторами, пока Windows держит файл.
- Окно «Запись остановлена»: фокус не уходит из окна, «Пропустить» всегда закрывает, окно остаётся при сорванном
  новом старте; выход во время старта выполняется.
- Горячая клавиша: сообщение про Shift верно и для стрелок и Tab; клавиша не показывается в текстах, когда занята;
  после скрытия окна снова работает.
- CI: проверка собранной программы со встроенным ffmpeg, `actions/*@v5`.

## Отложено на следующие планы

- **План 8:** Electron fuses в сборке.
- **План 8:** сторож для зависшего (не упавшего) окна записи — сейчас перезапуск только при падении его процесса.
- **План 4:** если остановить новую запись, пока окно «Запись остановлена» от предыдущей ещё открыто, новое окно
  заменяет старое (старая встреча сохранена, но без названия и числа участников).
- **План 4:** старые встречи в состоянии `error` с непустыми дорожками показывают «Готовим…» — нужен повтор сведения
  или пометка ошибки.
- Известное ограничение, не исправляется: если одна библиотека в OneDrive открыта сразу на Windows и на Mac,
  восстановление при запуске может пометить идущую на другом компьютере запись как прерванную. Пользователь держит
  библиотеку локально.
- Открытый вопрос про «Запись экрана» на Mac (выше).
