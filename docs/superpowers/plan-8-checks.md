## Решения при выполнении

- Тестовые подмены `TEXTMEET_*` работают только в версии для разработки и в тестовой копии сборки (файл-признак
  `resources/textmeet-test-build`, его кладёт `scripts/make-test-copy.mjs`); в выпуске переменные окружения ничего не
  меняют. Fuses выпуска: без запуска как Node, без `NODE_OPTIONS` и отладчика, с проверкой целостности app.asar —
  собранная программа на Windows с ними пишет, сводит и расшифровывает (проверено на тестовой копии, где проверка
  целостности тоже включена).
- Ширина колонки итогов хранится в `localStorage` окна (одна на программу); по умолчанию 38 %, от 20 до 60 % и не уже
  260 px; область уже 640 px — итоги сверху. Во время записи итогов рядом с «Остановить» есть «Свернуть».
- Пометка «не поместилось целиком» — у итогов, оборванных пределом длины ответа; поле в `ai.json` пишется только тогда.
- Лицензии моделей сверены с карточками моделей (Hugging Face, GitHub, ModelScope) — запрещающих нет. Две модели NVIDIA —
  под своими лицензиями (Nemotron — OpenMDW 1.1, Parakeet Unified — NVIDIA Open Model License): использование и
  распространение разрешены, в списке лицензий — нужная пометка.
- Сторож окна записи считает проверки без «сердцебиения» (15 с), а не время по часам — сон компьютера не принимается за
  зависание (найдено итоговым ревью).
- Оставшийся после падения движок итогов узнаётся по полному пути к `llama-server` (на Windows — через PowerShell), чужой
  процесс с тем же номером или другой `llama-server.exe` не трогается (найдено итоговым ревью).
- Мигание «Экспорт» (Плана 5) не воспроизвелось: текст той же встречи при перечитывании уже не пропадает.
- Модель расшифровки по умолчанию — **GigaAM v3**. С 2026-10-18 пробовали Whisper large-v3-turbo по умолчанию;
  2026-11-05 пользователь вернул GigaAM (точнее и быстрее на русском). Whisper остаётся в каталоге.

## Решение пользователя

- **ffmpeg для Mac.** Сборка ffmpeg из `ffmpeg-static` для Apple Silicon (osxexperts.net, FFmpeg 6.0) собрана с
  `--enable-gpl --enable-nonfree`; по правилам самого FFmpeg такую сборку распространять нельзя. Для Windows (gyan.dev,
  FFmpeg 6.1.1) — обычная GPL-3.0, её условия выполнены (текст лицензии и ссылка на исходники — в списке лицензий).
  До публикации Mac-установщика нужно решить: взять для Mac другую сборку ffmpeg (без nonfree) или выпускать как есть.
- **Решение (2026-11-22): оставить как есть.** Предлагались: своя сборка ffmpeg в `build.yml` (только нужное
  TextMeet, распространять можно), готовая сборка третьих лиц, текущая сборка. Пользователь выбрал текущую сборку;
  Mac-установщик выходит с ней. Это ограничение — в «Известных ограничениях» (Task 14).

## Отложено (найдено итоговым ревью, мелочи)

- Ошибка выгрузки «файл занят другой программой» показывается и тогда, когда в папку нельзя писать вовсе.
- Если старый движок итогов не завершился даже принудительно, его поздний выход может стереть файл номера нового.
- Ручка ширины на узкой области: доля может уйти ниже того, что показано (260 px), — несколько шагов «вхолостую».
- Сквозной тест смены размера окна не проверяет, что прокрутка текста сохраняется.
- Отвергнутый ответ GitHub (предварительная версия, чужая ссылка) не пишется в журнал отдельной строкой.
- Включение «Проверять, не вышла ли новая версия» не проверяет сразу — только через сутки или после перезапуска.
- Сторож окна записи начинает следить, когда окно сообщило о готовности, а не с его создания.
- Мелкое оформление кода: `UpdateBanner.tsx`, комментарий над `pasteCut`, повтор `windowStorage()`.
- Сквозные тесты плашки обновления: отрицательная проверка — по времени ожидания.
- Задание выпуска не сверяет метку с версией в `package.json`; повторный запуск падает, если черновик уже есть.
- `check-fuses` не падает, если выключена проверка целостности app.asar.
- «Закрыть» у «Модель сейчас занята» прячет и открытый блок с итогами.

## Известные ограничения

Всё, что осталось из «Отложено» Планов 1–9 (без исправленного в следующих планах), одним списком. Подробности — в
проверках соответствующего плана.

**Поставка и система**
- Mac: ffmpeg — сборка `ffmpeg-static` с `--enable-nonfree`; по правилам FFmpeg её нельзя распространять. Оставлена по
  решению пользователя (2026-11-22).
- Программа без платной подписи: при установке Windows и macOS предупреждают (как пройти — в README); у
  неподписанной сборки Mac разрешения могут сброситься после обновления (спецификация §9, риск 4).
- Mac: спрашивает ли система «Запись экрана» при первой записи, не записано (риск 7); скорость итогов на M4 16 ГБ не
  замерена.
- Общая библиотека в OneDrive, открытая сразу на Windows и Mac: восстановление при запуске может пометить идущую на
  другом компьютере запись как прерванную (План 2). Пользователь держит библиотеку локально.
- Версия программы до Плана 5 показывает импортируемую встречу и встречу из файла как «не удалось прочитать»; после
  отката на версию до Плана 6 свой запрос для ИИ пропадёт при следующем сохранении настроек.
- Поведение «Удалить в Корзину» на диске без Корзины вручную не проверено (Electron должен отказаться, а не удалить).

**Расшифровка и модели**
- На синтетической записи двух голосов длиной 3–4 ч без подсказки числа участников примерно в 1 случае из 10
  находится третий собеседник (План 3).
- При смене числа потоков во время расшифровки модель загружается заново — несколько секунд (План 3).
- Parakeet v3 иногда пишет короткие реплики латиницей; Whisper на процессоре — около получаса на час записи (План 7).
- Задача очереди, чьей модели ещё нет, ждёт идущего скачивания из каталога; отмена во время проверки суммы большого
  файла срабатывает не сразу и может оставить модель скачанной; «Отменить» удаляет всю группу файлов модели (План 7).
- «Повторить» во встрече берёт модель встречи, окно «Расшифровать» по умолчанию — модель из настроек (План 7).

**Текст встречи, удаление, поиск (План 4)**
- «Удалить аудио» в ту же секунду, когда встречу ставят в очередь, — задача кончится ошибкой.
- ffmpeg может мгновение держать файл после удаления встречи — перенос в Корзину повторяется 3 раза.
- «Вернуть» удалённую последнюю реплику спикера возвращает её как «Спикер N» — имя забыто.
- Удалённая встреча может мелькнуть в найденном до следующего обновления индекса.
- Встреча без реплик после исчезновения «Вернуть» показывает «В записи не найдено речи».
- Проверка «правка во время расшифровки» читает `meeting.json` вне очереди записи; `renameSpeaker` не проверяет, что
  спикер есть.

**Импорт и выгрузка (План 5)**
- При перекодировании звука полоска хода начинается заново; при нехватке места из-за квоты причина — «файл повреждён
  или формат не поддерживается»; редкие ошибки диска (EFBIG, ETIMEDOUT, EMFILE) — общей причиной.
- Окно может прислать в импорт любой полный путь, в том числе сетевой (программа только читает файл).
- Выгрузка сразу после правки на очень медленном диске может не захватить последнюю правку.
- Выход сразу после копирования звука — встреча остаётся «записано» (её можно расшифровать кнопкой).
- Если не удалось убрать папку неудачного импорта — встреча «создаётся», пока папку не удалят вручную; отмена импорта
  сравнивает папку библиотеки как строку.
- Строка ошибки слева закрывается только следующим действием; старое сообщение об отказах импорта может появиться
  снова; в одной цепочке добавлений отказы второй партии заменяют отказы первой.
- Составные эмодзи могут разрезаться на конце длинного имени; редкие имена устройств Windows (COM¹, CONIN$) не
  распознаются; окно сохранения может долго открываться, если прошлая папка — отключённая сетевая.
- Ошибка внутри обработчика хода копирования не перехватывается.

**ИИ (Планы 6, 9)**
- Пока кнопка показывает «Скопировано», «Экспорт» на 2 с сдвигается влево.
- Неудача сохранения запроса после ухода из настроек: при возврате — прежний запрос (ошибка видна слева); выход через
  трей в первые полсекунды после набора может не сохранить последние буквы; стандартный запрос говорит про «Я» и
  «Спикер N», даже если спикеров переименовали.
- Неудача запроса по встрече, с которой ушли, видна при следующем открытии этой встречи (текст объясняет причину).
- «Остановить» в первые доли секунды не срабатывает — запрос начнётся, его можно остановить следом.
- Испорченный файл модели правильного размера даёт общее «Модель не смогла ответить…».
- Вложенное оформление (`**жирный *курсив* жирный**`) — со звёздочками; вложенные списки — отдельными списками.
- После сохранения ответа на миг видны прежние итоги; удаление встречи останавливает её ответ, даже если удаление
  затем не удалось.
- Если старый движок итогов не завершился даже принудительно, его поздний выход может стереть файл номера нового.
- «Закрыть» у «Модель сейчас занята» прячет и открытый блок с итогами.

**Окно и настройки (План 8)**
- Ошибка выгрузки «файл занят другой программой» — и тогда, когда в папку нельзя писать вовсе.
- Ручка ширины на узкой области может сделать несколько шагов «вхолостую».
- Включение проверки новой версии проверяет не сразу, а через сутки или после перезапуска.
- Сторож окна записи следит с момента, когда окно сообщило о готовности, а не с его создания.

**Для разработки и тестов**
- Сквозные тесты: смена размера окна не проверяет прокрутку текста; плашка обновления — отрицательная проверка по
  времени; выход во время ответа не проверяет, что движок исчез; `test:llm` не проверяет ответ 401 без ключа;
  неудачное сохранение запроса подменяет обработчик main целиком; `FakeModelStore` не повторяет отказ `remove` во
  время `ensure`; удаление во время импорта не покрыто сквозным тестом. Один модульный тест однажды упал под сильной
  нагрузкой и не повторился (План 4).
- Задание выпуска не сверяет метку с версией в `package.json`, повторный запуск падает, если черновик уже есть;
  `check-fuses` не падает, если выключена проверка целостности `app.asar`; отвергнутый ответ GitHub не пишется в журнал
  отдельной строкой.
- Оформление кода: `UpdateBanner.tsx`, комментарий над `pasteCut`, повтор `windowStorage()`; строка «Скопировано» для
  экранного диктора — в двух кнопках; `AiSettings` записывает ссылку во время отрисовки.
- Служебные пункты Плана 1 (единая таблица IPC, раздельные tsconfig, порог покрытия по всем модулям) — см.
  [проверки Плана 1](plan-1-checks.md).
