Первая версия TextMeet для всех.

- Запись встреч и созвонов: ваш микрофон и звук компьютера, горячая клавиша, работа из трея.
- Расшифровка на вашем компьютере, с разбивкой по собеседникам; восемь моделей на выбор.
- Итоги встречи и вопросы к ней — моделью на вашем компьютере, без интернета.
- Поиск по всем встречам, правка текста, выгрузка в Word и в текстовый файл, импорт своих записей.

Как установить (Windows и Mac) и пройти предупреждение системы — в [README](https://github.com/wiiProfaker/TextMeet#readme).
