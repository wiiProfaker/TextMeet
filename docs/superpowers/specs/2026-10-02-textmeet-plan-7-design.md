# TextMeet — План 7 (свои модели Whisper): решения

**Дата:** 2026-10-02
**Основа:** [спецификация](2026-09-25-textmeet-design.md) §3.3, §3.6, §5.2, §5.4, §5.5, §6; [решения Плана 3](2026-09-29-textmeet-plan-3-design.md)

(лист 6 — настройки «Расшифровка»).
**Согласовано с пользователем 2026-10-02:**
- Другая модель нужна «просто для выбора» — конкретной жалобы на GigaAM нет; сравнение кандидатов (Qwen3-ASR,
  Parakeet v3) на записи пользователь не захотел.
- **Встроенной остаётся одна модель — GigaAM v3.** Другие модели пользователь скачивает сам, когда захочет; в настройках

- Модель выбирается в настройках (для новых встреч) **и** в окне «Расшифровать заново» (для одной встречи); во встрече
  подписано, какой моделью сделан текст.
- Подключается **любой файл Whisper в формате ggml (`.bin`)** — кнопка «Добавить свою модель Whisper…». Модели другого
  устройства (не Whisper) так не подключаются — их добавляем в код по просьбе.
- Видимая часть (§2) утверждена; после уточнения из неё убрана встроенная строка «Whisper large-v3-turbo» и добавлена
  ссылка «Где скачать модели Whisper».

## 1. Что входит в План 7

- Whisper через **whisper.cpp `whisper-server`** (отдельная программа): видеокарта NVIDIA (CUDA) на Windows, Metal на Mac,
  без видеокарты — процессор.
- **Свои модели Whisper** (ggml `.bin`, копируются в папку моделей) и ссылка, где их скачать.
- Выбор модели: настройки, окно «Расшифровать заново», подпись модели во встрече.
- Менеджер моделей: группа «Программа для Whisper» (только Windows — архив с видеокарточной сборкой whisper.cpp),
  скачивание архива с проверкой SHA-256 и распаковкой. Сама программа ставится автоматически — пользователь скачивает
  только файл модели.
- Сборка `whisper-server` для Mac в CI (Metal, один файл), встраивается в `.dmg`.

**Не входит:** встроенные модели Whisper (скачивает сам пользователь); другие виды моделей (Qwen3-ASR, Parakeet и т. п. — не захотели); выбор языка (Whisper всегда `ru`, как
в спецификации §5.4); выбор модели ИИ (План 6); переход по клику, правка текста, поиск (План 4).

**Почему whisper.cpp, а не Whisper внутри sherpa-onnx.** sherpa-onnx в Node работает только на процессоре: Whisper там
в 3–5 раз медленнее GigaAM, а свои модели пришлось бы переводить в ONNX. whisper.cpp считает на видеокарте (час записи —
минуты), а формат ggml — самый распространённый у готовых моделей Whisper (в том числе дообученных на русской речи).
Модуль Node поверх whisper.cpp отвергнут: нативная сборка под Electron на двух ОС хрупкая.

## 2. Интерфейс

- **Настройки → «Расшифровка».**
  - «Модель расшифровки» — выбор одной (переключатели):
    - **GigaAM v3** — «Лучше всего понимает русский. Работает на процессоре. Английские слова пишет русскими буквами.»
      (по умолчанию);
    - **свои модели** — имя (по умолчанию имя файла без `.bin`) и размер, кнопки «Переименовать» и «Убрать». Для них
      общее пояснение: «Модели Whisper понимают много языков и пишут английские слова латиницей. Работают на
      видеокарте.» На Windows, пока программа для Whisper не скачана, — «При первой расшифровке скачается программа для
      Whisper — 260 МБ».
    Под GigaAM — состояние, как в Плане 3: «скачана · 330 МБ» / «скачается при первой расшифровке».
  - Кнопка **«Добавить свою модель Whisper…»** → окно выбора файла (`*.bin`) → проверка заголовка (§4.4) → копирование
    в папку моделей с полосой «Копируем модель… 45 %» → строка появляется в списке. Исходный файл можно удалить.
    Неподходящий файл — «Это не модель Whisper (нужен файл ggml .bin)»; не хватает места — «Не хватает места на
    диске для модели (нужно 1,6 ГБ)».
  - Рядом с кнопкой — ссылка **«Где скачать модели Whisper»** (открывается в браузере) и подсказка: «Подойдёт любой
    файл ggml-….bin. Для начала — ggml-large-v3-turbo-q8_0.bin (870 МБ): быстрая и точная.» Ссылка ведёт на
    официальную страницу моделей whisper.cpp — `https://huggingface.co/ggerganov/whisper.cpp/tree/main` (адрес —
    постоянная в коде, открывается через `shell.openExternal`).
  - «Скачанные модели» (как в Плане 3) — строки «GigaAM v3», «Программа для Whisper»
    (только Windows), «Разделение по голосам и поиск речи» с размером и «Удалить». Свои модели здесь не повторяются —
    у них «Убрать» в списке выше. Удалять и убирать нельзя, пока идёт расшифровка (как в Плане 3).
  - Убрать модель, выбранную в настройках, → выбор возвращается к GigaAM v3.
- **Во встрече.** Под заголовком (рядом с датой и длительностью) — «Текст: GigaAM v3» /
  «Текст: <имя своей модели>». Имя своей модели запоминается в тексте встречи, поэтому подпись остаётся и после «Убрать».
- **«Расшифровать заново».** В окне, над вопросом о числе участников, — «Модель» (выпадающий список: все модели из
  настроек; если своих моделей нет — строки нет), по умолчанию — выбранная в настройках. Встреча расшифровывается выбранной; настройка не меняется.
- **«Расшифровать», «Повторить», окно «Запись остановлена»** — модель из настроек (на момент постановки в очередь).
- **Прогресс.** Новые этапы: «Скачиваем программу для Whisper — 120 из 260 МБ» (только Windows) и «Запускаем Whisper»
  (загрузка модели в видеокарту, секунды). Если видеокарта недоступна — под полосой «Видеокарта недоступна — Whisper
  работает медленно».

## 3. Данные

- **`settings.json`** (новые поля с `.default`, старый файл читается без миграции):
  - `asrModel: string` — id выбранной модели, по умолчанию `gigaam-v3-e2e-rnnt`;
  - `customWhisperModels: { id, title, size, addedAt }[]` — свои модели; `id` = `custom-` + 8 случайных
    `[a-z0-9]`, файл — `<папка моделей>/custom/<id>.bin`. Неизвестный или убранный `asrModel` читается как GigaAM.
- **Id моделей:** встроенная — `gigaam-v3-e2e-rnnt`; свои — `custom-…`. Каталог (id, название, вид: `gigaam` |
  `whisper`) собирается из встроенной модели и `customWhisperModels` — в `shared`, им пользуются и main, и окно.
- **`TranscribeRequest`** получает `model: string | null` (null — из настроек).
- **`meeting.json`** — поле `model` уже есть (План 3): пишется id модели этой расшифровки.
- **`transcript.json`** — `model` (id) уже есть; новое необязательное поле `modelTitle` (название на момент расшифровки)
  — для подписи во встрече. Старые тексты без него подписываются по каталогу («GigaAM v3»).
- **Задача очереди** хранит id модели; очередь, продолжающаяся после перезапуска, берёт его из `meeting.json`.

## 4. Как работает Whisper

### 4.1 Программа `whisper-server`
- **Хозяин — main** (новый модуль рядом с хозяином процесса расшифровки), а не процесс расшифровки: процесс
  расшифровки убивается при отмене, и дочерняя программа на Windows пережила бы его.
- **Запуск** по требованию — перед задачей с моделью Whisper: `whisper-server -m <файл> -l ru --host 127.0.0.1
  --port <свободный> -nc -sns -fa -t <потоки>` (`-fa` ускоряет работу на видеокарте и не мешает на процессоре —
  прототип это подтверждает). Готовность — ответ сервера на `GET /` (опрос каждые 200 мс, предел
  2 мин: загрузка большой модели с медленного диска). Приоритет — ниже обычного (`os.setPriority`), как у процесса
  расшифровки.
- **Видеокарта или нет** — по журналу программы при загрузке (строки ggml о найденном устройстве CUDA/Metal); нет —
  флаг «медленно» в прогрессе (§2) и запись в журнал. Точные строки фиксируются прототипом для закреплённой версии.
- **Жизнь:** одна программа на одну модель; задача с другой моделью Whisper → перезапуск с ней. Закрывается вместе с
  процессом расшифровки (5 минут простоя), при выходе из программы и при «Удалить»/«Убрать» модели. Падение во время
  задачи → встреча `error` «Whisper завершился с ошибкой» + «Повторить»; следующий запуск — заново.
- **Остатки после сбоя main:** PID и путь программы пишутся в `whisper-server.pid` в служебной папке; при запуске
  TextMeet, если процесс с этим PID жив и это наш `whisper-server` (совпадает путь), он завершается.
- **Сторож зависания** — тот же, что у процесса расшифровки (План 3 §5.2): процесс расшифровки шлёт прогресс после
  каждого куска; запрос к серверу без ответа дольше 2 мин → ошибка «Whisper не отвечает», программа перезапускается.
- **Порт** слушает только `127.0.0.1`.

### 4.2 Распознавание
- Конвейер не меняется (детектор речи, разделение по голосам, резка ≤ 20 с — sherpa-onnx, как в Плане 3); меняется
  только распознавание куска. Интерфейс `Recognizer` становится асинхронным (`recognize(): Promise<string>`), GigaAM
  остаётся как есть внутри.
- Whisper-распознаватель (в процессе расшифровки) отправляет кусок на `POST /inference`: WAV 16 кГц моно 16 бит,
  собранный в памяти; поля `temperature=0`, `temperature_inc=0.2`, `response_format=json`. Ответ — текст.
- **Защита от «галлюцинаций» Whisper** (на тишине и шуме он дописывает «Продолжение следует…», «Субтитры сделал …»,
  «Спасибо за просмотр» и зацикливается):
  - куски уже нарезаны детектором речи — чистая тишина в Whisper не попадает;
  - `-nc` (без контекста прошлых кусков) — ошибка одного куска не тянется в следующий;
  - текст куска, целиком совпадающий (без регистра и знаков) с фразой из списка известных — отбрасывается; список
    в коде, с тестами;
  - зацикливание (одна и та же фраза из 1–8 слов подряд больше 3 раз) — повторы обрезаются до одного.
- Потоки: на видеокарте процессору достаточно 4; без видеокарты — `min(8, ядер − 1)`. Во время записи число не
  меняется (сервер нельзя перенастроить на ходу, а перезапуск — это повторная загрузка модели); на видеокарте нагрузка
  на процессор и так мала. Ограничение записывается в «Отложено».

### 4.3 Поставка программы
- **Windows:** официальный архив whisper.cpp `whisper-cublas-11.8.0-bin-x64.zip` (≈ 260 МБ, сборка с CUDA и нужными
  библиотеками CUDA внутри; работает и без видеокарты — на процессоре) из выпуска, закреплённого в реестре (`b5130` =
  v1.9.4). Скачивается при первой задаче с Whisper как группа «Программа для Whisper»: архив → SHA-256 → распаковка
  (`extract-zip`) во временную папку → переименование в `whisper-runtime/` → метка `installed.json` (список файлов
  с размерами). Проверка «скачана» — по метке и размерам. Сборка 11.8, а не 12.4: в 2,5 раза меньше, а RTX 3070 и
  драйвер пользователя она поддерживает; прототип подтверждает, что она видит видеокарту.
- **Mac:** `whisper-server` собирается в `build.yml` из закреплённого тега whisper.cpp (`cmake -DGGML_METAL=ON
  -DGGML_METAL_EMBED_LIBRARY=ON -DBUILD_SHARED_LIBS=OFF`, один файл), кладётся в `resources/whisper/` через
  `extraResources`, подписывается ad-hoc, как ffmpeg. Скачивать на Mac нечего, кроме самой модели.
- **Linux (только `ci`):** официальный `whisper-bin-ubuntu-x64.tar.gz` того же выпуска — для теста с настоящей моделью.

### 4.4 Свои модели
- Проверка файла перед копированием: магическое число ggml (`0x67676d6c`) и параметры заголовка Whisper (размер
  словаря ≥ 51864, разумные число слоёв и размер окна звука); размер ≥ 30 МБ. Иначе — «Это не модель Whisper…».
- Копирование в `custom/<id>.part` → переименование; при ошибке `.part` удаляется. Место проверяется заранее.
- «Убрать» — удаляет файл и строку из настроек (не во время расшифровки).
- Задача с моделью, которой больше нет (убрана или файл пропал), → встреча `error` «Модель „<имя>“ удалена — выберите
  другую в „Расшифровать заново“»; кнопка «Повторить» здесь не показывается, только «Расшифровать заново».
- Модель, которую whisper.cpp не смог загрузить (файл прошёл проверку заголовка, но сломан), → встреча `error`
  «Whisper не смог загрузить модель „<имя>“»; подробности — в журнал.

## 5. Менеджер моделей

- Реестр (План 3 §6) получает группу `whisper-runtime` (только Windows, архив). Группа может быть отмечена ОС, на
  которой она нужна.
- Какие группы нужны задаче, решает модель: GigaAM → `gigaam` + `voices`; своя модель Whisper → её файл +
  `whisper-runtime` (на Windows) + `voices`.
- «Удалить» программу для Whisper или «Убрать» свою модель, пока работает `whisper-server`, — сначала программа закрывается.

## 6. Ошибки

| Ситуация | Что видит пользователь |
|---|---|
| Не скачалась программа для Whisper | Как в Плане 3: «Не удалось скачать модель расшифровки: нет связи с сервером» + «Повторить» |
| Архив программы повреждён / не распаковался | «Файл программы для Whisper повреждён, он будет скачан заново» + «Повторить» |
| `whisper-server` не запустился / не ответил за 2 мин | «Не удалось запустить Whisper» + «Повторить» (код и журнал программы — в журнал) |
| Модель не загрузилась в whisper.cpp | «Whisper не смог загрузить модель „<имя>“» + «Повторить» |
| Нет видеокарты / CUDA недоступна | Расшифровка идёт, в прогрессе «Видеокарта недоступна — Whisper работает медленно» |
| Программа упала во время задачи | «Whisper завершился с ошибкой» + «Повторить» |
| Запрос без ответа > 2 мин | «Whisper не отвечает» + «Повторить» |
| Своя модель убрана / файла нет | «Модель „<имя>“ удалена — выберите другую в „Расшифровать заново“» |
| Неподходящий файл при добавлении | «Это не модель Whisper (нужен файл ggml .bin)» |
| Мало места при добавлении / скачивании | «Не хватает места на диске для модели (нужно N)» |

## 7. Тестирование

- **Модульные (Vitest):** каталог и выбор групп по модели и ОС; настройки (старый файл, неизвестный id → GigaAM);
  проверка заголовка ggml; сборка WAV в памяти; фильтр «галлюцинаций» и обрезка повторов; хозяин `whisper-server` с
  подменной программой (маленький Node-сервер): запуск, готовность, перезапуск под другую модель, падение,
  зависание, закрытие, остатки по PID-файлу; распаковка архива (докачка, неверная сумма, битый архив); очередь с
  моделью задачи; добавление/убирание своей модели (копирование, `.part`, место).
- **Сквозные (Playwright, подменный движок):** «Добавить свою модель…» (подменный файл с заголовком ggml) → она в списке, в
  «Расшифровать заново» и выбирается в настройках → «Расшифровать» → подпись «Текст: <имя>»; ссылка «Где скачать»
  открывает адрес (перехват `openExternal`); «Убрать» → выбор вернулся к GigaAM, встреча со своей моделью показывает «удалена».
- **С настоящей моделью:** в `ci` (Linux) — официальный `whisper-server` + `ggml-tiny.bin` (75 МБ, кеш) на эталонной
  записи: текст не пустой, русские слова; на этом ПК (прототип) — рекомендуемая в подсказке ggml-large-v3-turbo-q8_0
  на CUDA: скорость и текст на записи из `TextMeet-samples`; в `build.yml` на Mac — собранный `whisper-server` с `ggml-tiny.bin` распознаёт эталон.
- **Ручная проверка** на Windows и Mac: скачать модель по ссылке из настроек, добавить её, первая
  расшифровка (на Windows — со скачиванием программы), скорость на часе записи, «Расшифровать заново» другой моделью, выход во время расшифровки
  Whisper (программа не остаётся висеть — Диспетчер задач / Мониторинг системы).

## 8. Изменения спецификации

- §3.3: модели — GigaAM v3 (встроенная, по умолчанию) и свои модели Whisper (ggml), которые пользователь скачивает
  сам по ссылке из настроек; выбор в настройках и
  в «Расшифровать заново»; подпись модели во встрече.
- §3.6: «модель расшифровки» — с «Добавить свою модель Whisper…» и ссылкой «Где скачать модели Whisper».
- §5.4: `AsrEngine.id` — `gigaam-v3-e2e-rnnt` или `custom-…`; `whisper-server` принадлежит main (§4.1).
- §5.5: модели Whisper приносит пользователь (встроенной нет); на Windows — архив whisper.cpp с CUDA 11.8; на Mac — своя сборка в CI.
- Дорожная карта: План 7 — «свои модели Whisper: whisper.cpp, добавление файла, выбор модели».
