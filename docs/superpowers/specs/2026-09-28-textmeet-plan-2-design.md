## 1. Что входит в План 2

- Новый вид всего приложения по макету: боковая панель (блок записи, список встреч по дням, кнопка настроек),
  правая часть — встреча / идущая запись / настройки.
- Запись двух дорожек (микрофон + звук компьютера) кусками на диск, индикаторы уровня, таймер.
- Старт и стоп: кнопка в окне, меню трея, глобальная горячая клавиша (переназначается в настройках).
- Звук и уведомление при старте/стопе; значок трея с красной точкой; меню трея «Начать/Остановить запись».
- После «Стоп» — окно «Запись остановлена»: название + «Сколько человек было на встрече, включая вас?».
- `audio/mix.opus` (сведение для прослушивания) через ffmpeg и простой плеер во встрече.
- Восстановление после сбоя (программы и окна записи), напоминание о тишине, проверка места на диске,
  понятные сообщения об ошибках доступа к микрофону и звуку компьютера.
- Настройки: раздел «Запись» (микрофон, звук компьютера по умолчанию, горячая клавиша, звуковой сигнал)
  и «Общие» (папка библиотеки, автозапуск).
- Отложенное из Плана 1 (§7 ниже).

**Не входит** (нарисовано в макете, но делается позже): поиск (План 4), «Импорт файла» (План 5), текст встречи,
спикеры, правка, переход по клику к месту записи (Планы 3–4), итоги и ИИ (План 6), разделы настроек
«Расшифровка» и «ИИ» (Планы 3, 6, 7). В Плане 2 этих элементов в интерфейсе **нет** — никаких неработающих кнопок.

## 2. Интерфейс (по макету)

**Оформление.** Тёплая «бумага»; заголовки, таймер и текст встречи — Literata, интерфейс — Golos Text (шрифты
встраиваются в программу через `@fontsource`, без интернета). Светлая и тёмная тема — по системе. Цвета — токены
из `project/tm.css` макета, перенесённые в `styles.css`. Красный — только для записи; основная кнопка — тёмная «чернильная».

**Окно** (1100×720, минимум 720×480):
- **Блок записи** — всегда вверху боковой панели.
  - Ожидание: красная кнопка «Начать запись» с подсказкой клавиши; переключатель «Звук компьютера»
    («Выключите, если встреча вживую, без созвона»); строка с названием микрофона.
  - Запись: «Идёт запись» + таймер, индикаторы «Микрофон» и «Звук компьютера» (20 делений), кнопка «Остановить»
    с подсказкой клавиши. Проблема со звуком компьютера — пометка «не слышно» у индикатора.
- **Список встреч** — группы «Сегодня», «Вчера», «25 сентября» (год — если не текущий). В строке: название,
  «время начала · длительность», пометка только если есть о чём сказать: «● идёт запись · 23:41», «записано»,
  «восстановлена после сбоя», «ошибка», «создаётся…», «не удалось прочитать».
- **Кнопка настроек** внизу боковой панели; настройки открываются в правой части, список остаётся.
- **Правая часть:**
  - идущая запись (выбрана в списке): название, «Запись идёт с 14:30 · сохраняется на диск каждую секунду»,
    крупный таймер, два широких индикатора с названиями устройств, «Остановить запись», подсказки, внизу —
    свободное место и «Если программа закроется со сбоем, запись восстановится при следующем запуске»;
    жёлтая плашка, если звук компьютера не слышен (§3.4);
  - встреча: название, «дата, время · длительность · N участников», пометка о статусе, плеер `mix.opus`
    (воспроизведение/пауза, время, перемотка, скорость 1× / 1,5× / 2×), кнопка «Открыть папку встречи»;
  - встреча, которую не удалось прочитать, и встреча «создаётся» — с пояснением;
  - ничего не выбрано — подсказка «Выберите встречу слева или начните запись — {клавиша} работает из любой программы».
- **Окно «Запись остановлена»** — поверх окна: длительность, поле «Название» (заполнено названием по умолчанию),
  вопрос о числе участников — кнопки 2–6 и поле «другое» (1–50), пояснение, «Пропустить» / «Расшифровать».
  До Плана 3 «Расшифровать» только сохраняет ответ (пользователь предупреждён).

**Редкие предупреждения — системными окнами** (`dialog.showMessageBox`), тексты как в макете: «Мало места на диске»
перед стартом и «Идёт запись» при выходе. Причина: они возникают и когда главное окно скрыто (старт клавишей поверх
созвона, выход из трея), а системное окно видно поверх всего.

**Уведомления** (тексты — лист 8 макета): «Запись началась», «Запись остановлена · N мин», «Запись всё ещё идёт»,
«Мало места на диске», «Горячая клавиша занята», «Запись восстановлена». Щелчок по уведомлению открывает окно.

## 3. Поведение записи

### 3.1 Старт
Источники: кнопка, пункт трея, горячая клавиша — все вызывают одно действие «начать / остановить».
1. Если запись уже идёт — это «стоп» (§3.3).
2. Свободное место в папке библиотеки < 1 ГБ → системное окно «Мало места на диске» (Отмена / Всё равно начать).
3. macOS: `systemPreferences.askForMediaAccess('microphone')`; отказ → ошибка «Нет доступа к микрофону» (§3.5).
4. Создаётся папка встречи со статусом `recording` (при сбое создания — пустая папка удаляется).
5. Звуковой сигнал старта (если включён) — **до** начала захвата.
6. Окно записи получает команду: id встречи, микрофон, писать ли звук компьютера.
7. Окно записи: `getUserMedia` (микрофон, без эхо-/шумоподавления и АРУ) и, если включено, `getDisplayMedia` по рецепту
   спайка (вариант Г; видео сразу останавливается). По `MediaRecorder` на дорожку, WebM/Opus 64 кбит/с, кусок раз в секунду.
8. Ответ «записываю» с временем старта каждой дорожки → main: таймер, значок трея с точкой, меню трея, уведомление
   «Запись началась», состояние в главное окно.

Переключатель «Звук компьютера» в боковой панели действует на **ближайшую запись** и после каждой записи
возвращается к значению из настроек: если однажды выключить его для живой встречи, следующий созвон не останется
без звука компьютера.

### 3.2 Во время записи
- Куски каждой дорожки идут из окна записи в main по IPC (`ArrayBuffer`, порядок сохраняется) и дописываются в
  `audio/mic.webm`, `audio/system.webm`. Ошибка записи на диск (нет места и т. п.) → запись останавливается
  с сохранением уже записанного и сообщением.
- Уровни (пик по каждой дорожке, 0–1 в шкале −60…0 дБ) — ~15 раз в секунду: окно записи → main → главное окно
  (только если оно видно) и проверки ниже.
- **Тишина:** обе дорожки тише −50 дБ 10 минут подряд → уведомление «Запись всё ещё идёт»; следующее — только
  после того, как звук появится и снова пропадёт на 10 минут.
- **Место на диске:** раз в минуту; меньше 500 МБ → одно уведомление «Мало места на диске» за запись.
- **Микрофон отключили** (дорожка завершилась) → плашка «Микрофон отключился. Звук компьютера продолжает записываться»;
  если звука компьютера нет — запись останавливается как по «Стоп».

### 3.3 Стоп
1. Окно записи останавливает `MediaRecorder`-ы, досылает последние куски, отвечает «остановлено»
   (ожидание не дольше 10 с).
2. Main закрывает файлы, пишет в `meeting.json`: статус `recorded`, длительность (по часам main), дорожки
   и их сдвиги. Сигнал стопа (если включён) — **после** остановки захвата. Уведомление «Запись остановлена · N мин».
3. Главное окно показывается (если было скрыто) с окном «Запись остановлена»; ответ сохраняется в `meeting.json`
   (`participantsHint`, `title`). «Пропустить» оставляет `participantsHint = null`.
4. В фоне ffmpeg сводит дорожки в `audio/mix.opus` (моно, Opus 48 кбит/с, с учётом сдвига дорожек); пока идёт
   сведение, плеер пишет «Готовим запись для прослушивания…». Сведение идёт по очереди, по одной встрече.

### 3.4 Звук компьютера не слышен
- `getDisplayMedia` отказал (`NotReadableError`, `AbortError`, …) → запись продолжается только с микрофоном,
  в окне и боковой панели — «Звук компьютера не записывается» с причиной.
- Дорожка есть, но **с начала записи** уровень ровно 0 дольше 10 с → жёлтая плашка
  «Звук компьютера пока не слышен» (Mac: «…скорее всего, нет разрешения „Запись системного звука“» + кнопка
  «Открыть настройки системы»; Windows: «Если созвон уже идёт, проверьте, что его звук идёт через этот компьютер»).
  Плашка исчезает, как только звук появился, и больше за эту запись не показывается. Проверка только «с начала»,
  потому что на Windows тишина в созвоне — тоже ровный 0, и плашка мигала бы посреди встречи.

### 3.5 Ошибки доступа
- Микрофон недоступен (`NotAllowedError`, `NotFoundError`, `NotReadableError`) → запись не начинается, пустая папка
  встречи удаляется; в блоке записи — сообщение с причиной и «Открыть настройки системы»
  (Windows `ms-settings:privacy-microphone`, Mac — раздел «Микрофон» в «Конфиденциальность и безопасность»).
  Если окно скрыто (старт клавишей) — ещё и уведомление; щелчок открывает окно.
- Все тексты — по-русски, без технических кодов; код и подробности — в журнал.

### 3.6 Восстановление после сбоя
- **Сбой программы:** при запуске main ищет встречи со статусом `recording` — раз программа только что
  запустилась, это прерванные записи. Каждая: статус `recorded`, `recovered: true`, длительность — по сведённому
  `mix.opus` (ffmpeg), уведомление «Запись восстановлена». Если дорожек нет или они пустые — статус `error`
  с текстом «Запись прервалась, звук не сохранился».
- **Сбой окна записи** (`render-process-gone`) во время записи → то же самое сразу, без перезапуска программы;
  окно записи создаётся заново, признак «готово» сбрасывается до его нового сигнала.
- При запуске в очередь сведения ставятся и все записанные встречи без `mix.opus` (например, сведение прервал выход).

### 3.7 Выход и выключение компьютера
- «Выход» во время записи → «Идёт запись» (Продолжить запись / Остановить и выйти). Отмена выхода сбрасывает признак
  выхода, чтобы закрытие окна снова прятало его в трей. Перед выходом дописывается журнал.
- Выключение / выход из системы во время записи — запись останавливается без вопросов (успеет — хорошо,
  не успеет — поможет восстановление).

## 4. Горячая клавиша

- Настройка `recordHotkey` (формат Electron accelerator) или `null` = по умолчанию для ОС:
  `Control+Space` (Windows), `Alt+Space` (macOS). Показывается по-человечески: `Ctrl+Space`, `⌥ Space`.
- Регистрируется при запуске. Не удалось → уведомление «Горячая клавиша занята» и предупреждение в настройках;
  запись по-прежнему доступна кнопкой и из трея.
- «Изменить» → поле ждёт комбинацию; на это время действующая клавиша временно снимается (иначе нажатие текущей
  комбинации начало бы запись вместо ввода), Esc — отмена. Правила (уточнение §3.1 спецификации):
  - нужна хотя бы одна из клавиш Ctrl, Alt/Option, Win/Cmd — или одна клавиша F1–F24;
  - **Shift с буквой — нельзя**: это просто заглавная буква, она мешала бы печатать;
  - одиночные буквы, цифры, пробел, Enter, Esc, Tab — нельзя (понятное сообщение, почему);
  - новая комбинация сразу регистрируется; занята → сообщение, остаётся прежняя.
- «Сбросить» — значение по умолчанию для текущей ОС.
- Разбор нажатия (`KeyboardEvent.code` + модификаторы → accelerator), проверка правил и показ — чистые функции
  в `src/shared/hotkey.ts` с модульными тестами.

## 5. Устройство

### 5.1 Модули

```
src/shared/
  ipc.ts            # таблица контракта: канал → аргумент → ответ; события main → окна; сообщения окна записи
  recording.ts      # типы состояния записи, уровней, команд окна записи; шкала уровня (дБ → 0–1)
  hotkey.ts         # accelerator: разбор нажатия, правила, показ
src/main/
  recording/controller.ts   # автомат записи: idle → starting → recording → stopping (без Electron, зависимости внедряются)
  recording/track-files.ts  # файлы дорожек: дописывание кусков по очереди, закрытие, ошибки диска
  recording/monitors.ts     # тишина 10 мин, «звук компьютера не слышен», место на диске
  recording/recovery.ts     # поиск и закрытие прерванных записей
  audio/ffmpeg.ts           # путь к ffmpeg (в т. ч. из app.asar.unpacked), запуск, разбор длительности
  audio/mixer.ts            # очередь сведения mix.opus
  hotkey-manager.ts         # регистрация / замена / приостановка globalShortcut (register внедряется)
  media-protocol.ts         # протокол tm-media:// для плеера (только файлы audio/ встреч библиотеки, Range)
  notifications.ts, texts.ts, permissions.ts, app-menu.ts, tray.ts (+ состояние записи)
src/renderer/recorder/
  capture.ts        # getUserMedia / getDisplayMedia / MediaRecorder / куски
  levels.ts         # AnalyserNode → пики
  sounds.ts         # сигналы старта и стопа (WebAudio, без файлов)
src/renderer/main/
  App.tsx, Sidebar/RecordPanel/MeetingList, panes (Meeting, LiveRecording, Settings), StopDialog, Player,
  HotkeyField, хуки состояния записи и списка встреч
```

### 5.2 IPC
- Контракт — одна таблица типов в `src/shared/ipc.ts`; preload и main пользуются типизированными обёртками,
  расхождение ловит проверка типов. Входные данные от окон по-прежнему проверяет zod в main, отправитель —
  по `event.sender` (окно записи не может звать API главного окна и наоборот).
- Главное окно: запросы (настройки, список встреч, старт/стоп, ответ окна «Запись остановлена», горячая клавиша,
  открыть папку встречи / настройки системы) и события (`recording:state`, `recording:levels`, `library:changed`,
  `stop-dialog:open`).
- Окно записи: команды от main (`start`, `stop`, `play-sound`) и сообщения в main (`ready`, `started`, `chunk`,
  `levels`, `track-ended`, `system-failed`, `failed`, `stopped`).

### 5.3 Данные
- **Настройки** (новые поля с умолчаниями): `microphoneId: string | null` (null — как в системе),
  `recordSystemAudio: boolean = true`, `recordHotkey: string | null = null`, `recordSounds: boolean = true`.
- **meeting.json** (новые поля с умолчаниями): `tracks: [{ kind: 'mic' | 'system', file, startOffsetMs }] = []`,
  `recovered: boolean = false`. Незнакомые поля (от будущих версий, библиотека может быть общей через OneDrive)
  **сохраняются** при перезаписи.
- **Файлы встречи:** `audio/mic.webm`, `audio/system.webm` (если был звук компьютера), `audio/mix.opus`.
- Папка встречи без `meeting.json` — «создаётся», а не «повреждена».

### 5.4 ffmpeg
- Пакет `ffmpeg-static` (бинарник под ОС сборки; в CI — под Windows x64 и macOS arm64), в установленной программе —
  из `app.asar.unpacked`. На Mac бинарник подписывается ad-hoc вместе с остальным.
- Нужен уже здесь для `mix.opus`; дальше им же пользуются расшифровка (План 3) и импорт (План 5).

### 5.5 Разрешения и безопасность
- `session.setPermissionRequestHandler` / `setPermissionCheckHandler`: захват звука — только окну записи; главному
  окну — только проверка `media` (чтобы видеть названия микрофонов в настройках); всё остальное запрещено.
- `setDisplayMediaRequestHandler` отвечает только окну записи.
- macOS: урезанное меню приложения (TextMeet: О программе, Скрыть, Выход; Правка — для копирования/вставки;
  без «Перезагрузить» и инструментов разработчика).
- Electron fuses — в Плане 8 (доводка), после проверки разрешений на Mac.

## 6. Тестирование
- **Модульные (Vitest):** автомат записи (старт, отказ микрофона, отказ звука компьютера, стоп, сбой окна записи,
  повторный старт/стоп, выход во время записи), файлы дорожек, мониторы (тишина, «не слышен», место), восстановление,
  разбор длительности ffmpeg, горячая клавиша (разбор, правила, показ, замена с откатом), схемы, группировка
  списка по дням, форматирование. Порог 80 % — по всем модулям `src/`, кроме явно перечисленной склейки с Electron
  и React-компонентов.
- **Сквозные (Playwright):** поддельные устройства Chromium (`--use-fake-device-for-media-stream`,
  `--use-fake-ui-for-media-stream`) для микрофона; звук компьютера — тестовой подменой (сигнал / отказ), включаемой
  только переменной окружения, как `TEXTMEET_USER_DATA`. Сценарии: запись со звуком компьютера → стоп → окно
  «Запись остановлена» → файлы и `meeting.json` → `mix.opus` → плеер; без звука компьютера; отказ звука компьютера;
  отказ микрофона; восстановление при запуске; сбой окна записи во время записи; горячая клавиша в настройках;
  выход во время записи.
- **Ручная проверка** (контрольная точка с пользователем) на Windows и Mac: созвон с системным звуком, живая встреча,
  горячая клавиша поверх созвона во весь экран, трей, уведомления, сбой (снятие процесса), разрешения macOS после
  `tccutil reset` — заодно ответ на открытый вопрос спайка, нужна ли «Запись экрана».

## 7. Отложенное из Плана 1, которое закрывается здесь
Перезапуск окна записи после сбоя и сброс «готово»; обработчик разрешений; урезанное меню macOS; удаление пустой папки
при сбое создания встречи; сохранение незнакомых полей `meeting.json`; таблица контракта IPC; порог покрытия по всем
модулям; раздельные tsconfig для main/preload и окон; сброс признака выхода при отмене и запись журнала перед выходом;
русские тексты системных ошибок (`EACCES`, `ENOSPC`, `EBUSY`…); «создаётся» вместо «повреждена»; `predev`/`prestart`
со скачиванием Electron; уборка временных папок модульных тестов; `actions/*@v5`.
Electron fuses переносятся в План 8.
