# TextMeet — План 7 (каталог моделей расшифровки): решения

**Дата:** 2026-10-02
**Основа:** [спецификация](2026-09-25-textmeet-design.md) §3.3, §3.6, §5.4, §5.5, §6; [решения Плана 3](2026-09-29-textmeet-plan-3-design.md)
(конвейер, очередь, менеджер моделей); [проверки Плана 3](../plan-3-checks.md); [макет](https://claude.ai/artifact/Urmc3atvSFifUpDyBzjeR6)
(лист 6 — настройки «Расшифровка»).
**Согласовано с пользователем 2026-10-02:**
- Другая модель нужна «просто для выбора» — жалобы на GigaAM нет.
- Нужен **каталог моделей, как в программе Handy** (пользователь прислал снимок экрана): карточки с языками, размером,
  полосками «точность» и «скорость», кнопками «Скачать» / «Удалить»; пользователь сам решает, что скачать.
- В каталоге — модели, понимающие русский, **и** модели только для английского.
- Кнопки «Добавить свой файл модели» **нет** — хватит каталога; новую модель в каталог добавляем по просьбе.
- Все модели работают **на процессоре** (как GigaAM); ускорение на видеокарте — потом, отдельным планом.
- Модель выбирается в настройках (для новых встреч) **и** в окне «Расшифровать» / «Расшифровать заново» (для одной
  встречи); во встрече подписано, какой моделью сделан текст.

Первые версии этого документа (Whisper через whisper.cpp и свои файлы ggml) отменены: каталог проще и даёт больше
выбора. Всё работает на том же движке sherpa-onnx, что и GigaAM, — новой программы рядом с TextMeet не появляется.
Решения ниже уточнены прототипом (§9): числа, языки и состав каталога — по его замерам.

## 1. Что входит в План 7

- Каталог моделей в коде: GigaAM v3 (как сейчас) + 7 новых (§3). Скачивание, отмена и удаление по карточке.
- Распознаватель для каждого вида моделей (sherpa-onnx: transducer NeMo, Qwen3-ASR, Whisper, Canary, потоковые T-one и
  Nemotron) за общим интерфейсом `Recognizer`.
- Раздел настроек «Расшифровка» в виде каталога; выбор модели в окне «Расшифровать»; подпись модели во встрече.
- Защита от «галлюцинаций» (§4.3).

**Не входит:** видеокарта; свои файлы моделей; выбор языка встречи (§4.2); выбор модели ИИ (План 6); правка текста,
поиск (План 4).

## 2. Интерфейс

- **Настройки → «Расшифровка»** — каталог в стиле «Бумага»:
  - Сверху — **«Выбрана»**: карточка текущей модели (рамка цвета чернил).
  - **«Скачанные»** — карточки скачанных моделей; кнопки «Выбрать» и «Удалить».
  - Затем не скачанные — две группы: **«Понимают русский»** и **«Только английский»**; кнопка «Скачать».
  - **Карточка:** название и автор («Parakeet v3 · NVIDIA»), одна строка описания, полоски «точность» и «скорость»
    (5 делений), языки («Только русский» / «25 языков» / «Русский · знает 30 языков» у многоязычных моделей, которым
    закреплён русский), размер в мегабайтах («скачана · 639 МБ»), пометка «Рекомендуется» — только у GigaAM v3.
    Во время скачивания — «Скачиваем — 120 из 671 МБ» (с общими моделями голосов), полоса и «Отменить».
  - Скачивание из карточки берёт и общие модели голосов, если их нет. Одновременно скачивается одна модель:
    остальные «Скачать» недоступны, пока она не скачается или её не отменят. «Отменить» стирает недокачанное.
  - Не скачалось — причина в карточке, кнопка «Повторить».
  - «Удалить» недоступно, пока идёт расшифровка или скачивание. Удалили выбранную модель → выбор возвращается к
    GigaAM v3. Выбранная, но не скачанная модель (так бывает с GigaAM) — «Скачается при первой расшифровке.»
  - Строка «Разделение по голосам и поиск речи · 32 МБ» с «Удалить» — отдельным полем «Общие модели», если скачаны.
- **Модели только для английского** помечены в карточке («Только английский — русская речь распознаётся неверно») и в
  выборе модели.
- **Во встрече.** В строке под заголовком (дата · длительность · участники) — «Текст: GigaAM v3», «Текст: Parakeet v3».
  Название запоминается в тексте встречи — подпись остаётся и после удаления модели.
- **Окно «Расшифровать» / «Расшифровать заново».** Над вопросом о числе участников — «Модель» (выпадающий список:
  все модели каталога, нескачанные — «скачается, 639 МБ», английские — «только английский»); по умолчанию — модель
  из настроек. Встреча расшифровывается выбранной; настройка не меняется.
- **Окно «Запись остановлена»** — модель из настроек на момент ответа. **«Повторить»** после ошибки — та же модель,
  что не справилась (её id в `meeting.json`).
- **Прогресс встречи** — как в Плане 3; на этапе скачивания — название модели: «Скачиваем модель Parakeet v3 — 120 из
  671 МБ» (мегабайты, чтобы число заметно росло).

## 3. Каталог

| Модель | Автор | Языки в TextMeet | Размер | Вид в sherpa-onnx | RTF* | Скорость / точность |
|---|---|---|---|---|---|---|
| **GigaAM v3** (по умолчанию) | Сбер | только русский | 311 МБ | transducer (как в Плане 3) | 0,035 | 5 / 5 |
| **Parakeet v3** | NVIDIA | 25 языков, сама определяет | 639 МБ | transducer NeMo | 0,063 | 4 / 3 |
| **Qwen3-ASR 0.6B** | Alibaba | русский (знает 30) | 941 МБ | qwen3Asr | 0,21 | 2 / 4 |
| **Whisper large-v3-turbo** | OpenAI | русский (знает ~100) | 989 МБ | whisper | 0,55 | 1 / 3 |
| **Nemotron 3.5** | NVIDIA | русский (знает 40) | 651 МБ | потоковый transducer | 0,19 | 3 / 3 |
| **T-one** | Т-Банк | только русский | 138 МБ | потоковый toneCtc | 0,057 | 4 / 3 |
| **Parakeet Unified EN 0.6B** | NVIDIA | только английский | 632 МБ | transducer NeMo | 0,075 | 4 / 5 |
| **Canary 180M Flash** | NVIDIA | только английский | 198 МБ | canary | 0,22 | 2 / 3 |

\* Время распознавания на секунду речи: Ryzen 7 3700X, 7 потоков, без разделения по голосам, 5 минут записи
пользователя (английские — английский пример). Полоска «скорость»: RTF ≤ 0,05 — 5 делений, ≤ 0,1 — 4, ≤ 0,2 — 3,
≤ 0,35 — 2, иначе 1. «Точность» — по прочтению текстов прототипа и опубликованным замерам.

- **Moonshine Base** (в первом списке) **убрана**: на кусках до 20 с она часто возвращала пустой текст, и на 8–10 с
  тоже.
- **Источник файлов:** у всех моделей — отдельные файлы с Hugging Face из зеркал автора sherpa-onnx (`csukuangfj`,
  `csukuangfj2`), адреса закреплены на коммите, у каждого файла размер и SHA-256. Архивы не нужны — тот же
  скачиватель, что у GigaAM.
- **Проверка на обеих ОС:** `npm run test:catalog` — каждая модель распознаёт эталон (русские — стихи из примера
  GigaAM, английские — английский пример); workflow `models-check` (запуск по кнопке) гоняет его на Windows, Mac и
  Linux.

## 4. Как это работает

### 4.1 Распознаватели
- Интерфейс `Recognizer` (План 3) не меняется: `recognize(samples): string`. Конвейер (детектор речи, разделение по
  голосам, резка ≤ 20 с) — как в Плане 3, для всех моделей.
- Каталог (`shared/asr-models.ts`) — то, что видит человек; файлы — в реестре (`main/models/registry.ts`); настройки
  sherpa-onnx — в `main/transcription/asr-config.ts` (чистые данные, проверяются без нативного кода).
- Потоковые модели (T-one, Nemotron): кусок подаётся целиком с тишиной до и после, затем «конец ввода» и
  декодирование до конца. Без запаса тишины они теряли начало и конец реплики: Nemotron — 0,5 с до и 2,5 с после,
  T-one — 0,3 с и 1,5 с; T-one считает признаки на 8 кГц. Whisper получает 1 с тишины после куска — без неё он
  обрывал последнее слово.
- Процесс расшифровки держит одну модель расшифровки (кеш по папке моделей и модели): смена модели между встречами
  освобождает прежнюю.
- Модель не загрузилась (файлы целы, но движок их не принял) — процесс сообщает об этом отдельным кодом.

### 4.2 Язык
- Автоопределение языка на коротких кусках путало русский: Qwen3 выдавала китайский, Whisper — английский. Поэтому
  **русский закреплён** у Qwen3-ASR, Whisper и Nemotron, английский — у Canary. У Parakeet v3 настройки языка нет —
  на коротких репликах («да», «алло») она иногда пишет их латиницей; это сказано в её описании.
- Для встреч на английском — английские модели каталога.

### 4.3 «Галлюцинации»
На шуме модели дописывают «Продолжение следует…», «Субтитры сделал …», «Спасибо за просмотр» и зацикливаются
(«Эээээээ…» у Whisper в прототипе). Защита — для всех моделей: куски уже нарезаны детектором речи; кусок, целиком
совпадающий (без регистра, «ё» и знаков) с фразой из списка известных или начинающийся с подписи субтитров,
отбрасывается; одна и та же фраза из 1–8 слов подряд больше 3 раз сокращается до одной; одна буква подряд 6 раз и
больше — до трёх.

### 4.4 Скорость и нагрузка
Как в Плане 3: приоритет ниже обычного, потоки `min(8, ядер − 1)`, во время записи — 2. Медленные модели (Whisper,
Qwen3) на часе записи работают десятки минут — это видно по полоске «скорость» до скачивания. Доли прогресса
учитывают скорость модели (распознавание медленной модели — большая часть работы). Сторож зависания не меняется:
процесс сообщает о ходе после каждого куска ≤ 20 с, а кусок даже у Whisper — секунды.

## 5. Данные

- **`settings.json`** — новое поле `asrModel` (id из каталога, по умолчанию GigaAM); неизвестный id читается как GigaAM,
  остальные настройки при этом не сбрасываются.
- **`TranscribeRequest`** получает `model` (null — из настроек).
- **`meeting.json`** — поле `model` (было в Плане 3): пишется при постановке в очередь, по нему расшифровка
  продолжается после перезапуска; у встреч Плана 3 (`null`) и с неизвестной моделью — GigaAM (в журнал — запись).
- **`transcript.json`** — `model` (id) и новое необязательное `modelTitle` (название на момент расшифровки) — для
  подписи во встрече. Старые тексты без него подписываются по каталогу («GigaAM v3»), неизвестная модель — своим id.
- **Модели на диске** — в той же папке моделей, по папке на модель; группа «voices» — общая для всех.

## 6. Ошибки

| Ситуация | Что видит пользователь |
|---|---|
| Не скачалась модель из карточки | В карточке — причина (как у расшифровки в Плане 3) и «Повторить» |
| Файл повреждён | «Скачанный файл модели повреждён — при повторе он скачается заново.» |
| Мало места | «Не хватает места на диске для модели расшифровки: нужно N МБ свободного места.» |
| Модель не загрузилась в движок | Встреча `error` «Не удалось загрузить модель «<название>». …журнал» + «Повторить» |
| Удаление во время расшифровки / скачивания | «Модели нельзя удалить, пока идёт расшифровка / скачивается модель.» |
| Встреча на английской модели | Без ошибки; в выборе и карточке — пометка «только английский» |
| Модель встречи пропала из каталога | Расшифровка — GigaAM v3, в журнал — запись |

## 7. Тестирование

- **Модульные (Vitest):** каталог, реестр (у каждой модели файлы в своей папке, адреса закреплены), отмена скачивания,
  менеджер моделей по группам, скачивание из каталога (одно за раз, отмена, ошибка, частота сообщений), состояние для
  окна, настройки, `transcript.json`, конфиги sherpa-onnx для каждой модели (используют все свои файлы и только их),
  фильтр «галлюцинаций», конвейер и очередь с моделью, раскладка карточек и подписи.
- **С настоящими моделями:** `npm run test:models` (как в Плане 3, только GigaAM — в `ci`), `npm run test:catalog`
  (все модели, ~4,5 ГБ) — локально и в workflow `models-check` на трёх ОС.
- **Сквозные (Playwright):** поддельное хранилище моделей (`FakeModelStore`, шаги скачивания —
  `TEXTMEET_TEST_DOWNLOAD_MS`) и поддельные движки: каталог (скачать, отменить, выбрать, удалить выбранную),
  расшифровка выбранной в окне моделью и подпись «Текст: …».
- **Ручная проверка** на Windows и Mac: скачать 2–3 модели, расшифровать одну встречу разными моделями через
  «Расшифровать заново», отменить скачивание, удалить модель, выход во время скачивания.

## 8. Изменения спецификации

- §3.3: модели — каталог (§3 этого документа), GigaAM v3 по умолчанию; выбор в настройках и в окне «Расшифровать»;
  подпись модели во встрече. Whisper — одна из моделей каталога, на процессоре (sherpa-onnx), а не whisper.cpp.
- §3.6: «модель расшифровки» → «каталог моделей расшифровки».
- §5.1, §5.2, §5.4: whisper.cpp / `whisper-server` убираются; модель расшифровки — id из каталога.
- §5.5: источники моделей — по каталогу.
- §6: строка «Нет видеокарты / CUDA недоступна для Whisper» убирается (видеокарта — будущий план).
- Дорожная карта: План 7 — «каталог моделей расшифровки (на процессоре)»; ускорение на видеокарте — новый план
  «потом».
