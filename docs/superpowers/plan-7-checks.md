## Сделано сверх плана

### По проверке прототипа

- Отмена скачивания, которое ещё ждёт своей очереди, срабатывает сразу, не дожидаясь чужого скачивания.
- Скачивание моделей для задачи очереди отменяемое: повторная постановка той же встречи («Расшифровать заново»
  другой моделью) и выход из программы прерывают и скачивание.
- Если подготовка моделей идёт дольше 0,7 с (первая проверка сумм, ожидание другого скачивания), во встрече —
  «Готовим модель …».
- Фильтр выдумок («Продолжение следует…», зацикливание) — только у Whisper и Qwen3: у других моделей такие фразы —
  настоящая речь.
- Ранняя загрузка модели: модель расшифровки загружается в начале, и если движок её не принял, встреча узнаёт об этом
  за секунды, а не после чтения звука и разделения по голосам.
- На карточке скачанной модели не остаётся старая ошибка прошлого скачивания.
- Адреса файлов GigaAM и pyannote закреплены на коммите, как у остальных моделей.

### По ревью кода всей ветки (коммиты `276f907`..`2fd927e`, всё с тестами)

- Уже скачанная модель встречи не ждёт чужого скачивания из каталога.
- Если Windows (антивирус, индексатор) ненадолго держит скачанный файл, переименование повторяется; не вышло — понятная
  ошибка диска.
- Ошибка удаления моделей — простая фраза; сырой текст с путями — только в журнале.
- При смене модели процесс расшифровки перезапускается, чтобы память прежней модели (у Whisper ≈ 1 ГБ) освободилась
  сразу.
- Задача, взятая из очереди во время выхода из программы, не начинает скачивание моделей.
- После подготовки моделей ход встречи переходит со «скачивания» к следующему этапу.
- Фокус клавишей Tab не уходит из окна с выпадающим списком (выбор модели).
- Кнопка «Повторить» на карточке названа для экранного диктора своим видимым словом.
- Счётчик байтов не зачитывается диктором каждые полсекунды (ход виден по полоске); сквозной тест скачивания не
  гоняется со временем — его проверки успевают и на медленной машине.
- Ошибка чтения каталога исчезает после удачного чтения.

## Отложено

- **Видеокарта** (CUDA на Windows, Metal на Mac) — отдельным планом потом.
- Задача очереди, чьей модели ещё нет, ждёт идущего скачивания из каталога (в это время — «Готовим модель …»); если
  модель встречи уже скачана — не ждёт.
- Скачивание, начатое очередью, не показывается ходом на карточке каталога.
- `FakeModelStore` (сквозные тесты) не повторяет отказ `remove` во время `ensure`.
- Известное ограничение: Parakeet v3 иногда пишет короткие реплики («да», «алло») латиницей — сказано в её описании.
- Известное ограничение: Whisper на процессоре — около получаса на час записи.
- Отмена во время проверки суммы большого файла срабатывает не сразу; если отмена пришлась на последний файл, модель
  может остаться скачанной.
- «Отменить» удаляет всю группу файлов модели, включая уже проверенные.
- «Повторить» во встрече берёт модель встречи, а окно «Расшифровать» по умолчанию — модель из настроек. Модель встречи
  меняется при постановке в очередь, даже если повторная расшифровка потом не удалась.
- Если список моделей в окне «Расшифровать» не загрузился, выбор модели молча скрыт — берётся модель из настроек.
- Из прошлых планов по-прежнему открыты пункты «Отложено» [Плана 3](plan-3-checks.md) и вопрос про «Запись экрана» на
  Mac ([проверки Плана 2](plan-2-checks.md)).
