# TextMeet — дорожная карта планов

Спецификация: [2026-09-25-textmeet-design.md](../specs/2026-09-25-textmeet-design.md)

Проект разбит на последовательные планы. Каждый план даёт работающий и проверяемый результат.
Подробно расписан только **План 0 (спайк)** — от его результатов зависят детали всех остальных
(какой вариант GigaAM, работает ли sherpa-onnx внутри Electron, как писать системный звук на macOS 27).
Подробный план следующего этапа пишется после завершения предыдущего.
